# HelpBridge

Веб-застосунок, що з'єднує людей, які потребують допомоги, з незалежними волонтерськими фондами. Заявник подає одну заявку у спільний пул, доступний усім схваленим фондам, замість того щоб окремо звертатись до кожного фонду. Фонди верифікують заявки, призначають волонтерів на збори та відстежують їх виконання аж до закриття з підтверджуючими доказами.

Проєкт з курсу «Основи роботи з фреймворком Spring Boot», Факультет інформатики, НаУКМА.
